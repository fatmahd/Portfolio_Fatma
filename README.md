# Fatma Haddad Portfolio

Portfolio website inspired by Wissem's structure, rebuilt with Fatma Haddad SOC Analyst data from her PDF.

## Run with Docker Compose

```bash
docker compose up --build -d
```

Then open:

- http://localhost:8080

## Stop

```bash
docker compose down
```

## Project files

- index.html: structure and content
- styles.css: visual system and responsive layout
- script.js: animations and dynamic experience rendering
- Dockerfile: container image with Nginx
- docker-compose.yml: local deployment stack
- nginx.conf: static hosting and cache rules
